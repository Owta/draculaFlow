# Dracula Flow Bash Quote Script

A simple Bash script that displays a random Dracula Flow quote when run, or when the user's terminal emulator opens.

---


## Requirements

- Bash (v4+ recommended)
- A text file containing one quote per line  
  *(Default: `/home/{user}/Projects/draculaFlow/quotes.txt`)*

---

## Usage

```bash
bash <path to quotify.sh>
```
Keep Quotes.txt file in the same folder with dracula.sh
